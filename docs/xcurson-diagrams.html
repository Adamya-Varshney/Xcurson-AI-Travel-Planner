Authentication Flow

Dual auth paths (email/password and Google OAuth) both converge into Supabase session management.

%%{init: {'theme': 'dark', 'themeVariables': {'primaryColor': '#6c5ce7', 'primaryTextColor': '#e4e7ef', 'primaryBorderColor': '#a29bfe', 'lineColor': '#8b90a0', 'secondaryColor': '#232733', 'tertiaryColor': '#1a1d27', 'fontSize': '14px'}}}%%
sequenceDiagram
    participant U as User
    participant SPA as React SPA
    participant SA as Supabase Auth
    participant EF as Edge Functions
    participant DB as PostgreSQL

    rect rgb(35, 39, 51)
    Note over U,DB: Email/Password Path
    U->>SPA: Enter credentials
    SPA->>SA: signUp / signInWithPassword
    SA-->>SPA: Session + JWT
    end

    rect rgb(35, 39, 51)
    Note over U,DB: Google OAuth Path
    U->>SPA: Click "Sign in with Google"
    SPA->>SA: signInWithOAuth("google")
    SA-->>U: Redirect to Google
    U-->>SA: Authorize
    SA-->>SPA: Session + JWT
    end

    rect rgb(35, 39, 51)
    Note over U,DB: Authenticated Requests
    SPA->>SPA: Store JWT in localStorage
    SPA->>EF: POST /functions/v1/* + Bearer JWT
    EF->>SA: Verify JWT via getUser()
    SA-->>EF: User object
    EF->>DB: Query with user_id (RLS enforced)
    DB-->>EF: Scoped results
    EF-->>SPA: JSON response
    end
